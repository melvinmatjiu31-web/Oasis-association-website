Oasis Association Website

About the Project

This project is a responsive website developed for Oasis Association. Its purpose is to provide visitors with information about the organisation, its services, community projects, and ways to get involved.

The website was developed using HTML5, CSS3, and JavaScript. It includes responsive layouts, interactive functionality, form validation, and search features.

Website Pages

The website contains five main pages:

1. Home ("index.html") – Introduces Oasis Association.
2. About Us ("about.html") – Provides information about the organisation.
3. Services & Projects ("services.html") – Describes services and projects and includes a search feature.
4. Get Involved ("enquiry.html") – Allows visitors to make enquiries about getting involved.
5. Contact ("contact.html") – Displays contact information and includes a contact form.

Design and Development

The website uses an external CSS stylesheet to maintain a consistent design across all pages.

CSS Flexbox and Grid were used to organise page layouts. Responsive design was implemented using CSS media queries to adapt the website to desktop, tablet, and mobile screen sizes.

Relative units, including percentages and "rem", were used to improve responsiveness.

Hover and focus effects were added to navigation links, buttons, and interactive elements. Images use responsive sizing to adapt to different screen sizes.

Part 3: Enhanced Functionality and SEO

JavaScript Functionality

JavaScript was added to improve the website's interactivity.

The implemented features include:

- A search function on the Services & Projects page.
- Dynamic filtering of service and project cards.
- A message when no matching search results are found.
- Form validation for required fields.
- Email address validation.
- Helpful feedback messages when forms are submitted.
- A smooth appearance effect for page sections.

Forms

The Enquiry and Contact pages contain forms for visitors to enter their details and messages.

JavaScript checks the entered information and displays feedback when the form passes validation.

Note: The forms are demonstrations and do not send messages to the organisation. A form submission service or backend would be required to receive submissions.

Search Engine Optimisation (SEO)

SEO metadata was added to all five HTML pages.

The metadata includes:

- Page descriptions.
- Relevant keywords.
- Author information.

Descriptive alternative text (ALT text) was also checked on the website's images to improve accessibility and help describe image content.

Responsive Design

The website was designed to adapt to different screen sizes, including:

- Desktop computers.
- Tablets.
- Mobile phones.

CSS media queries help the navigation and content adjust to smaller screens.

Accessibility

The website uses descriptive image ALT text where images are present, clear headings, navigation links, and labelled form fields.

These features help improve usability and make the website easier to navigate.

How to Run the Website

1. Download or clone the project repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in a web browser, or use the Live Server extension.
4. Navigate through the website using the navigation menu.
5. Test the Services & Projects search and the forms.

Version Control

GitHub was used to store and manage the website source code. Changes were committed and pushed to the repository during development.

Conclusion

The Oasis Association website provides visitors with information about the organisation, its services, and ways to get involved. The addition of JavaScript search functionality, form validation, SEO metadata, and responsive design improves the website's usability and functionality.
