## Oasis Association Website

## About the Project

This project is a responsive website created for Oasis Association.

The purpose of the website is to provide visitors with information about
Oasis Association, its services, projects and ways to get involved.

#Website Pages

The website contains five main pages:

1. Home
2. About Us
3. Services & Projects
4. Get Involved
5. Contact

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- GitHub

## Design and Development

The website uses an external CSS stylesheet to maintain a consistent
design across all pages.

CSS Flexbox and Grid were used to organise the page layouts.

Responsive design was implemented using CSS media queries so that the
website can adapt to desktop, tablet and mobile screen sizes.

Relative units such as percentages and rem were used to improve
responsiveness.

Hover and focus effects were added to navigation links, buttons and
interactive elements.

Images use responsive sizing so that they can adapt to different
screen sizes.

## Responsive Design

The website was tested at different screen sizes, including:

- Desktop
- Tablet
- Mobile

The navigation and content adjust to smaller screen sizes using CSS
media queries.

## Accessibility

Alternative text was added to images to help describe visual content.

Clear headings, navigation links and form labels were used to improve
the website's usability.

## Testing
