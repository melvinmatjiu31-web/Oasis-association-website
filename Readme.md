Oasis Association Website

1. Project Overview

This project is a multi-page website developed for Oasis Association, a non-profit organisation that creates opportunities and provides support for people with intellectual disabilities.

The purpose of the website is to provide visitors with clear information about Oasis Association, its services and projects, and the different ways people can support the organisation.

2. Organisation

Organisation: Oasis Association

Website: Oasis Association

Oasis Association provides services and programmes including workshops, day centres, group homes, adult groups and income-generating projects such as recycling, charity shops and bakery-related activities.

3. Target Audience

The website is intended for:

- People with intellectual disabilities and their families.
- Caregivers.
- Volunteers.
- Donors.
- Businesses and potential partners.
- Community members.
- People interested in Oasis services and programmes.

4. Website Objectives

The main objectives of the website are to:

1. Introduce visitors to Oasis Association.
2. Explain the organisation's mission and services.
3. Provide information about Oasis projects.
4. Encourage visitors to support the organisation.
5. Provide clear contact information.
6. Provide an enquiry form for potential supporters and visitors.
7. Create a professional and user-friendly online presence.

5. Website Pages

The website contains five main HTML pages.

Home

File: "index.html"

The homepage introduces Oasis Association and provides an overview of its services, impact and ways visitors can get involved.

About Us

File: "about.html"

This page provides information about the organisation's history, mission, values and the people it supports.

Services & Projects

File: "services.html"

This page describes Oasis programmes and projects, including workshops, day centres, group homes, adult groups, recycling, charity shops, bakery activities and outsourced business services.

Get Involved

File: "enquiry.html"

This page explains different ways visitors can support Oasis and contains an enquiry form.

Contact

File: "contact.html"

This page provides Oasis Association's contact information and information about some of its locations.

12. Responsive Design

CSS media queries were used to make the website responsive.

On smaller screens:

- Navigation changes to a vertical layout.
- Service cards change from multiple columns to a single column.
- Images resize to fit the screen.
- Text sizes are adjusted.
- Hero buttons become easier to use on mobile devices.

13. Accessibility

Accessibility was considered during development by:

- Using semantic HTML elements.
- Adding "alt" text to images.
- Using labels for form fields.
- Using headings to organise content.
- Providing clear navigation.
- Using readable text sizes.
- Ensuring sufficient contrast between text and backgrounds.

14. Conclusion

The Oasis Association website provides a simple, informative and responsive online presence for the organisation.

The website introduces visitors to Oasis Association, explains its services and projects, provides contact information and gives visitors an opportunity to make enquiries and get involved.
